## [Keyv 及其他 npm 包受活跃的“沙丘魔虫”供应链攻击影响](https://www.aikido.dev/blog/keyv-and-friends-compromised-in-npm-supply-chain-attack) ⭐️ 9.0/10

热门 npm 包 Keyv 及其他 78 个相关包已在一场活跃的“沙丘魔虫”供应链攻击中被攻陷，导致 353 个版本被注入窃取凭证的恶意软件。攻击者通过入侵 Keyv 维护者的 GitHub 账户获取访问权限，并利用此权限在其所有包组合中传播恶意代码。 这次攻击至关重要，因为它影响了 Keyv 等每周下载量超过 1.27 亿的广泛使用的 npm 包，对众多项目构成重大安全威胁，并可能导致凭证大规模被盗和进一步的系统入侵。它凸显了软件供应链固有的脆弱性以及加强依赖管理安全措施的必要性。 “沙丘魔虫”攻击被描述为一种利用 npm 生态系统自动化传播的蠕虫，它污染了 79 个包的 353 个版本，并窃取了开发者和 CI 凭证。此次事件是继 s1ngularity 攻击和 Josh Junon 包被入侵之后，针对 npm 生态系统的第三次重大供应链攻击。

hackernews · cimi_ · 8月4日 11:01 · [社区讨论](https://news.ycombinator.com/item?id=49166874)

**背景**: 软件供应链攻击是一种网络攻击，它通过针对软件开发和分发过程中安全性较低的环节（例如第三方库或构建工具）来注入恶意代码。一旦被入侵，这些恶意代码可以感染所有受影响软件的用户，使其成为一种广泛进行网络间谍活动或破坏的有效方法。npm（Node Package Manager）是 JavaScript 运行时 Node.js 的包管理器，被开发者广泛用于共享和重用代码，由于其庞大的依赖生态系统，因此经常成为此类攻击的目标。

中国教育部发布《义务教育阶段科学教育"做中学"领航行动指南》，要求从 2026 年秋季新学期起，4 至 9 年级每名学生每学期至少完成 1 项科学探究任务，且每个任务不少于 4 课时。 这一重大的全国性教育政策转变，通过推广动手实践和项目式学习，并明确纳入人工智能（AI）和新兴产业等关键领域，将对中国的 STEM 素养和未来人才培养产生深远影响。 该指南聚焦“真实问题”开展跨学科项目式学习，提供生命健康、生态环境、地球奥秘、航空航天、新兴产业、人工智能六大探究主题，并以纪实方式记录学生的问题意识、实践和合作能力，纳入综合素质评价档案，不再另设考试。
